Online battles
==============

You can play 1P vs 2P against a friend on another PC. One of you hosts the
battle and the other joins it. You don't need to change any settings on
your router.

Before you start, both of you need:
- the same version of BT2 Recomp, and
- your own copy of the game in the "data" folder.


Connecting
----------
To connect, you swap two codes in any chat app, such as Discord or
WhatsApp.

1. The host opens bt2-launcher.exe, chooses Online battle, then HOST.
   A code like SC07-3ZKY is copied automatically. The host pastes it
   (Ctrl+V) into the chat.

2. The friend copies the host's code from the chat. In the launcher they
   choose Online battle, then JOIN. The copied code is filled in by
   itself (if it isn't, they paste it with Ctrl+V). Then they press Enter.
   A reply code is now copied automatically. The friend pastes it into the
   chat.

3. The host copies the reply code from the chat, clicks on the game's
   window and presses Ctrl+V. A box opens with the code in it. The host
   presses Enter.

The battle then starts by itself.

The first time, Windows may ask whether bt2-entry-probe.exe may use the
network. Choose Allow.

If you are both on the same home network, it's even easier: the friend can
use the host's "Home code" instead, and no reply code is needed.


During the battle
-----------------
Both games open on the Dueling screen, with every fighter unlocked. Choose
1P vs 2P. The host is 1P and the friend is 2P. A line at the top of the
screen tells you which one you are.

A controller keeps working while you type in the chat. The keyboard only
works while the game's window is in front.

Escape, or the menu button on a controller, opens the online menu. Choose
Resume to carry on, or End online battle to stop. While the menu is open,
the game waits for both players.


If it won't connect
-------------------
- Check that the host pasted the friend's newest reply code.
- If you see "different build" or "gameplay settings differ": you both
  need the same version of BT2 Recomp, and the same "Beam struggles by
  buttons" setting (in Settings > Controls). Other settings, such as HD
  textures, widescreen or 60 fps, may be different.
- Still not connecting? Swap roles, so that the friend hosts. Some mobile
  and work networks can't be reached this way.
- If you see "Connection slow", or the game pauses a lot: the host can
  raise the Input delay, in Online battle > Connection settings.

If a battle stops with "the two games went apart", please report it and
attach both players' "user\last-run.log" files.
