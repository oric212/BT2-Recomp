# BT2 Recomp v0.1

The first release of BT2 Recomp: *Dragon Ball Z: Budokai Tenkaichi 2* (PS2, USA, SLUS-21441) as a native Windows program. The game's own code is recompiled for the PC; it is not an emulator.

**You need your own copy of the game.** Nothing of the game is in this download: put your USA disc image (`.iso`) into the `data` folder.

## Install and play

1. Download `BT2-Recomp-v0.1.zip` and unzip it anywhere (not inside Program Files).
2. Put your game's `.iso` into the `data` folder.
3. Start `bt2-launcher.exe`, look through Settings, choose **Play**.

Windows 10 or 11 (64-bit) and a graphics card with Vulkan drivers. `README.txt` in the download has the details; `ONLINE-SETUP.txt` explains online battles.

## What's in it

- Every game mode: story, Ultimate Battle Z, tournaments, training, versus battles with one or two controllers.
- Saves on memory cards in the `saves` folder, the same as the original's.
- Online 1P vs 2P with a friend on another PC, with no router setup.
- Optional, in the launcher: HD texture packs (PCSX2 format, not included), super-sampling, widescreen, 60 fps battles, fast loading, Quick start. None of them changes how the game plays.

## Known issues

- Story mode has been partly tested.
- 60 fps battles: the destroyed Namek stage can flicker.
- HD textures: fighters under water are not in HD; a texture can briefly look wrong in the first fight.
- Online: the "press O to recover" prompt is sometimes not shown.

If the game stops, `user\last-run.log` has the messages; please include it in a report.
